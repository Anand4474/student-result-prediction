# Student Result Prediction — Docker and GHCR Practical

A small educational FastAPI project that predicts a result category from study hours and attendance. It includes a synthetic sample dataset, a training script, API endpoints, Docker setup, and the supplied Practical 8 document.

> **Important:** This is a starter implementation created for the ZIP package. It is not the user's original Practical 7 project and has not been claimed as tested. The bundled data is synthetic and the model is for demonstration only.

## Run locally (Windows PowerShell)

1. Install Python 3.11+ and Docker Desktop if you want to use Docker.
2. Open PowerShell in this project folder.
3. Create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Train the model from the bundled sample data:

```powershell
python train_model.py
```

5. Start the API:

```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

6. Open `http://127.0.0.1:8000/docs`. Health check: `http://127.0.0.1:8000/health`.

Example request for `POST /predict`:

```json
{
  "study_hours": 4.5,
  "attendance": 80
}
```

## Run with Docker

Build the image:

```powershell
docker build -t student-result-prediction:latest .
```

Run it:

```powershell
docker run --rm -p 8000:8000 --name student-result-prediction student-result-prediction:latest
```

Then open `http://localhost:8000/docs`.

If port 8000 is already in use, map another host port:

```powershell
docker run --rm -p 8001:8000 student-result-prediction:latest
```

Then visit `http://localhost:8001/docs`.

## Publish to GitHub Container Registry (GHCR)

Replace `<github-username>` with your lowercase GitHub username. Create a GitHub Personal Access Token (classic) with `write:packages` and `read:packages`; never commit or share the token.

```powershell
docker login ghcr.io -u <github-username>
docker tag student-result-prediction:latest ghcr.io/<github-username>/student-result-prediction:v1
docker tag student-result-prediction:latest ghcr.io/<github-username>/student-result-prediction:latest
docker push ghcr.io/<github-username>/student-result-prediction:v1
docker push ghcr.io/<github-username>/student-result-prediction:latest
docker pull ghcr.io/<github-username>/student-result-prediction:v1
docker run --rm -p 8000:8000 ghcr.io/<github-username>/student-result-prediction:v1
```

For safer interactive authentication in PowerShell, use a secure prompt and pipe the token to Docker:

```powershell
$token = Read-Host "GitHub token" -AsSecureString
$plainToken = [System.Net.NetworkCredential]::new("", $token).Password
$plainToken | docker login ghcr.io -u <github-username> --password-stdin
Remove-Variable token, plainToken
```

Do not paste a real token into screenshots, project files, chat, or GitHub.

## Troubleshooting

- **Model file missing:** run `python train_model.py` from the project root.
- **Port is in use:** use `-p 8001:8000` and open port 8001 locally.
- **Docker daemon unavailable:** start Docker Desktop and wait until the engine is running.
- **GHCR denied:** verify username, token permissions, package ownership, and package visibility.
- **Different Practical 7 image name:** adapt the `docker tag` source to the image shown by `docker images`.
